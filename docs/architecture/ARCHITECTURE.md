# Architecture Overview
**Last updated:** 2025-10-07
**Project:** Harmonia Rząska Real Estate

## Tech Stack

### Core
- **Framework:** Next.js 15.5.3 (App Router primary)
- **Language:** TypeScript 5.x (strict mode)
- **Styling:** Panda CSS 1.4.1 (zero-runtime)
- **CMS:** Payload CMS 3.56.0
- **Database:** PostgreSQL (Supabase Transaction Pooler)

### Key Libraries
- React 19.1.0
- React Aria Components 1.12.2 (WCAG compliance)
- Lucide React 0.468.0 (icons)
- Sharp 0.33.5 (image optimization)
- Resend (email - planned)

## Routing Architecture

### App Router (Primary)
- `/` - Homepage with unit listings
- `/mieszkania/[slug]` - Dynamic unit detail pages
- `/admin` - Payload CMS admin (handled by Payload)
- `/api/*` - API routes (Payload + custom)

### Legacy Pages Router (Being Phased Out)
- Minimal usage, migrating to App Router

## Data Flow
User Request
↓
Next.js App Router
↓
Server Component (app/page.tsx)
↓
getPayload() → Payload CMS
↓
PostgreSQL (Supabase)
↓
Response

## Styling Architecture

### Panda CSS (Current - v1.4.1)
- **Pattern:** CSS-in-JS (zero-runtime)
- **Config:** `panda.config.ts`
- **Tokens:** Modern Green theme
- **Usage:** `import { css } from '@/styled-system/css'`

**4 Components Using Panda:**
1. `SiteHeader.tsx` - Main navigation
2. `ui/ArchitectureSection.tsx` - About section
3. `ui/Button.tsx` - Button components
4. `ui/UnitsSection.tsx` - Units listing

**Migration Status:** Migrated from Stitches (removed 2025-10-07)

### CSS Files (Legacy - Being Removed)
- `app/globals.css` - Basic resets
- `public/css/*` - Old styles (to be removed)

## Database Architecture

### Connection
- **Provider:** Supabase PostgreSQL
- **Mode:** Transaction Pooler (port 6543)
- **Connection:** Managed in `payload.config.ts`

### Collections (5 total)
1. **units** - Property listings
2. **media** - File uploads
3. **users** - Admin users
4. **contact-messages** - Contact form submissions
5. **site-settings** (Global) - Site configuration

### Key Relationships
- Units → Media (images)
- SiteSettings → Media (hero images, gallery)

## Component Architecture

### Component Patterns

**Server Components (Default)**
```typescript
// app/page.tsx
import { getPayload } from 'payload'

export default async function Page() {
  const payload = await getPayload({ config })
  const units = await payload.find({ collection: 'units' })
  return <div>{/* render */}</div>
}
```
Client Components (When Needed)
